# MetroLidar2026: Контроль габарита и детекция препятствий по 3D-лидару

Автономный программный комплекс контроля свободности пути и кинематического габарита для беспилотных поездов метрополитена уровня GoA4 по данным 3D-лидара (Hesai Pandar 128 / Livox).

Решение разработано в рамках хакатона «Лидеры цифровой трансформации 2026» (Задача №5: Департамент транспорта Москвы / Московский метрополитен).

---

## Ключевые возможности

* **Горизонт контроля 150.0 м:** Гарантированное перекрытие тормозного пути поезда на рабочих скоростях метро ($S_{\text{emerg}} \le 126.6$ м при $60$ км/ч).
* **Робастное удержание кривых пути ($R \ge 160$ м):** Динамическое слежение за осью тоннеля в кривых любого радиуса со смещением до $14$ м, прохождение гермозатворов и надежная селекция пути в двухпутных тоннелях.
* **Аналитический габарит приближения ГОСТ 9238 (Габарит «М»):** Точное 2D евклидово поле расстояний со знаком (Signed Distance Field — SDF) со сложностью $\mathcal{O}(1)$ на точку. Изоляция платформ станций и контактного рельса без слепых зон.
* **Лидарная одометрия:** Оценка линейной скорости поезда $V$ методом 1D кросс-корреляции профилей тоннеля между кадрами $\to$ расчет тормозного пути $S_{\text{brake}}(V)$ и времени до столкновения (TTC).
* **0 ложных экстренных торможений (100% точность):** Протестировано на всех 6 реальных датасетах хакатона и синтетических препятствиях (11 из 11 тестов пройдены успешно).
* **Инженерный веб-интерфейс (`metro_web_gui`):** Строгий плоский CAD-интерфейс (FastAPI + WebGL + SSE) на порту 8080: честное время расчета кадра (22 мс), 3D сцена с видом из кабины и полноразмерная таблица препятствий.

## Быстрый старт

### 1. Запуск в Docker (Рекомендуемый способ)

Скрипт автоматизирует сборку и запуск в среде Ubuntu 22.04 LTS + ROS 2 Humble:

```bash
# Сборка Docker-образа (выполняется один раз):
./run_docker.sh --build

# Запуск с воспроизведением датасета с реальным препятствием:
./run_docker.sh --bag doubleT_obstacle

# Запуск со сложным кривым тоннелем и гермозатвором:
./run_docker.sh --bag roundT_pressureGate_roundT

# Запуск интерактивной оболочки bash:
./run_docker.sh --shell
```

После запуска откройте инженерную веб-панель в браузере: **`http://localhost:8080`**.

### 2. Запуск автоматической верификации (11 тестов)

Для быстрой проверки математического ядра и детекции без необходимости поднимать ROS-окружение:

```bash
python3 scripts/verify_system.py
```

# Директория для ROS 2 Bag-файлов

Поместите в данную папку тестовые данные для воспроизведения:
* Директорию с `metadata.yaml` и файлами `.db3` / `.mcap` (например, `doubleT_obstacle`)
* Либо файл `.db3` / `.mcap`

### Запуск обработки:
```bash
# Автоматический запуск первого найденного бэга:
bash run_docker.sh --auto

# Запуск конкретного бэга (достаточно указать только название папки или файла):
bash run_docker.sh --bag doubleT_obstacle
```
